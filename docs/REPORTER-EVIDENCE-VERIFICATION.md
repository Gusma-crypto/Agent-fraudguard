# Reporter Verification & Evidence Validation

This **adds a safety layer without changing the FraudGuard concept**.

Reporter states: anonymous, unverified, verified, trusted_source. Reporter verification proves provenance, not the truth of the claim.

Evidence may include transaction references, screenshot/document references, message transcripts, URLs/domains, phone numbers, timestamps, recipient identifiers, and platform-generated events.

Always distinguish:
- FACT — directly supported
- CLAIM — reporter statement
- INFERENCE — system/model interpretation
- VERIFIED KNOWLEDGE — promoted by verification policy

A single unsupported report may create an observation but must not create a public label, external auto-block, or trusted memory.

Support disputes, evidence supersession, confidence reduction, reviewer notes, and revocation.
