# Inactive Reference Archive

Everything in this directory is historical material, not active FraudGuard/OpenClaw instruction.

- `openclaw-current/` preserves the original organizer-provided workspace files.
- `archive/openclaw-additions/` preserves merge snippets already applied to active root files.
- `archive/superseded-docs/` preserves documents whose unique rules were merged into canonical active sources.

Do not recursively load this directory during agent startup. Do not copy or merge these files over active root configuration unless the user explicitly requests a historical restore or comparison.
